Supported JSONPath syntax

Root $, .name, ["key"], indices including negative indices, wildcards, unions, slices and recursive descent. Filters support existence, ==, !=, <, <=, >, >=, &&, ||, ! and parentheses. Compare singular @ or $ paths with JSON literals. Functions and scripts are not supported. Results are always exported as an array.

$.records[*].id   $..name   $.records[?(@.id > 10)]   $[0:10:2]
