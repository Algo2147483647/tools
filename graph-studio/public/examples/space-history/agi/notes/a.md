# Reasoning tools and autonomous agents

An agent is evaluated as a system acting through time. Code generation supplies executable artifacts; retrieval supplies outside evidence; ReAct alternates reasoning with observation and action. Memory, reflection and skill libraries extend the system beyond one isolated model response.

Inference can also be organized as search. Intermediate steps, branching candidates, process rewards and verifiers create alternative ways to spend computation. Reasoning-focused reinforcement learning and test-time scaling make these choices central to recent capability development. A longer chain is useful only insofar as it improves correct decisions or reliable verification.

Mathematical and algorithmic agents reveal the value of checkable outputs, but research problems often lack an easy evaluator. Human direction and expert review remain part of many reported successes. Trace connections to older heuristic search and formal reasoning without assuming that a modern system has inherited every cognitive property claimed for those traditions.
