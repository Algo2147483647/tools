# Evolution meta-learning and open-ended learning

Fixed-task optimization leaves open how an intelligent system acquires new tasks, new representations and new challenges. Evolutionary methods search over populations; NEAT changes neural structure as well as weights; novelty search reduces dependence on a potentially misleading objective.

Meta-learning optimizes how quickly learning adapts. Curriculum learning organizes experience, while continual learning asks how to retain useful knowledge. POET combines generated environments and transfer between solutions. These forms of open-endedness are constrained by their chosen representations and environment generators.

Program-learning systems add reusable abstractions, and AlphaEvolve combines generated code with evolutionary selection under evaluators. This is a concrete bridge to AI-assisted algorithm improvement. It should be distinguished from an unconstrained machine that autonomously redesigns every component of its successor.
