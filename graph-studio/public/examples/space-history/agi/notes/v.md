# Definitions evaluations and debates

What counts as general intelligence changes how progress is measured. Turing emphasizes observable dialogue, critics question understanding or systematicity, and practical demonstrations expose gaps between specialist strength and general competence. Funding reviews evaluate particular programs rather than all possible intelligence.

Modern benchmarks measure different slices: subject knowledge, abstraction, software repair, web actions, desktop interaction and task horizon. ARC explicitly emphasizes skill acquisition, while Levels of AGI separates breadth, performance and autonomy. A score cannot be interpreted without knowing data exposure, compute, interface, scoring and human comparisons.

Read the 2026 interactive ARC result together with its harness conditions. State retention can change a system's result considerably even when its model name stays fixed. This strand therefore resists treating any leaderboard threshold as an automatic scientific declaration of AGI.
