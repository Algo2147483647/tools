# 史料与编选约定

本图据博物馆、图书馆、大学教学资料、学术研究及百科年表交叉编选，本次整理日期为 **2026年10月14日**。节点保存来源链接，以下导读保留事件与来源的对应。文字为简短独立概述，不是史料原文摘录。

## 年代与时期边界

多数记录只精确到年。所有正年补齐四位，公元前按ISO带符号六位天文年表示：公元前770年 = -000769，公元前221年 = -000220，公元前1年 = 0000。天文年编号与历史纪年之间有一年的编号差，不代表改动实际年代。年内排序不能表达该年内部的确切先后。

民国成立、武昌起义、清帝退位、五四运动和中华人民共和国成立保留公历日期；事件并不声称发生于日期起点的午夜。安世高条采用“约年”，毕昇条明确为年代范围，其他长期活动也按标题标明含义。

东周从前770年起，战国采用前475年分期。秦末采用参考年表前206年的口径；部分史著以前207年秦王投降为止。西汉前206年起点包含汉王时期，称帝是在前202年。唐条包含常见通史分期中的武周阶段，另以重叠时期条展示武周国号中断。元从1271年国号起，南宋至1279年，两者重叠。明条止于1644年北京政权结束，不否认南明延续。清条以1636年改国号为起点；后金、1644年迁都北京、南明和明郑另列。

1840—1842年鸦片战争条采用战事阶段；有些来源标题从1839年的冲突起算。1937—1945年条明确为全面抗战阶段，不排除1931年开始的抗战。民国只标成立事件，不给出虚构的1949年政权终止。

所选博物馆年表中个别正文存在与其表格不一致的日期，编选不机械照抄：秦统一用多源一致的前221年；西晋265年是建国，不写成当年灭吴；安史之乱只取755年爆发，不沿用将整个战争写至759年的简略条目。

## 关系解释

- **part-of**：某一事件或活动位于所选时期之内；不是严格意义的组织隶属关系。
- **reference**：标签明确描述的历史背景、共同主题、参与、更替或转折；不主张充分或唯一因果，也不将征服说成自愿融合。
- **sequence**：所选事件的先后次序，或标签明确说明的政权分立、更替；省略中间事件时会注明，先后本身不等于因果。
- **rendezvous**：不同政权路径交汇于明确的战争、议和、征服或政权转折事件；不表示参与方自愿合并，具体含义以边标签为准。

每条线的文字是具体解释。思想、技术和制度跨越许多地区、人物与时间，本图的主题联系不能代替完整传播史。分支汇入战争或政权转折节点时，只说明所标历史事件，不将征服、并存、交往统称为融合。
