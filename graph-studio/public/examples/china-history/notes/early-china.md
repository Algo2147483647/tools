# 春秋到汉初：从诸侯竞争到帝国治理

本次细化从公元前770年写到前141年，以武帝即位接续原图。阅读重点是政治权力、战争动员、制度和思想如何相互影响，而不是把所有事件排成一串必然走向秦统一的台阶。

主图可按下文的事件标题搜索。每个节点都有概要、时间精度和来源；[条目目录](./early-catalog.md)可按年代连续阅读，[来源约定](../SOURCES.md)说明纪年与关系线的含义。

## 一、王室东迁后，谁能维持诸侯秩序

周平王东迁后，王室仍拥有政治名号、礼仪权威和册命诸侯的地位，却越来越依赖诸侯的土地、军队与支持。周郑交质和繻葛之战显示，王与诸侯之间甚至需要交换人质、诉诸战争。但王权不是在某一天突然归零，后来晋文公接受王命、韩赵魏请求列侯，都还要使用这套政治语言。参见[《左传·隐公》](https://zh.wikisource.org/wiki/春秋左氏傳/隱公)与[《史记·周本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj004.html)。

齐桓公任用管仲，既整顿国内，也经营诸侯关系。葵丘会盟说明，霸主的影响不只来自打赢一仗，还来自协调盟国、处理争端以及借用周王室的名义。长勺之战则提醒我们：齐国的上升过程中也会遭遇失败。宋襄公在泓水败于楚，晋文公在城濮胜楚后组织践土会盟，这些转折不能压缩成一张固定的“五霸轮流上台”名单；五霸本来就有不同列法。参见[《左传·庄公》](https://zh.wikisource.org/wiki/春秋左氏傳/莊公)、[《史记·齐太公世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj032.html)与[《晋世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj039.html)。

读图路径：**周平王东迁 → 周郑交质 → 繻葛之战**；再分别看**齐桓公任用管仲 → 葵丘会盟**和**重耳返晋 → 城濮 → 践土**。这些路径相互关联，却不是同一国家连续不断的历史。

## 二、晋楚竞争、中小国求存与吴越兴起

晋楚之间的竞争，经常围绕郑、宋等国展开。郑既是重要通道，也有自己的政治利益，并非没有选择的棋子。邲、鄢陵等战役改变一时的联盟力量，却不能让任何一方永远控制中原。前546年宋国促成弭兵会盟，是对长期冲突的调整；它并未停止所有战争，吴楚战线仍在发展。参见[《楚世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj040.html)、[《郑世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj042.html)与[《宋微子世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj038.html)。

吴在柏举之战后进入郢都，是楚的严重危机，但楚后来得到秦援并恢复统治。因此，**攻入都城不自动等于永久灭国**。吴又与越交战：夫椒之战中越败，黄池会盟时吴北上争盟而越乘机进攻，前473年越才最终灭吴。图中吴的时期条到此结束，越的勾践时期条则继续向后，避免把双方画成同时消失。参见[《吴太伯世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj031.html)与[《越王勾践世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj041.html)。

同时，国家内部也在变化。鲁国初税亩触及土地收益与征收；郑铸刑书、晋铸刑鼎把刑法规范公开，引发旧贵族政治秩序下的争论。它们不等于现代税制或现代法治，却让我们看到国家如何更明确地管理土地、人口与处罚。参见[《左传·宣公》](https://zh.wikisource.org/wiki/春秋左氏傳/宣公)与[《昭公》](https://zh.wikisource.org/wiki/春秋左氏傳/昭公)。

## 三、从贵族掌权到战国改革

三家分晋与田氏代齐都不宜只用一个年份概括。晋的卿族竞争先改变实际权力，再改变政治名号，最后消灭旧君主保有的领地；齐则经历田氏掌权、田和获列侯、姜齐末君去世等阶段。

| 过程 | 关键年份 | 应区分的变化 |
| --- | --- | --- |
| 三家分晋 | 前453年 | 韩赵魏灭智氏并分地，晋君仍在 |
| 三家列侯 | 前403年 | 周王正式承认韩赵魏为诸侯 |
| 晋君余地结束 | 前376年 | 三家瓜分剩余晋地 |
| 田常杀简公 | 前481年 | 田氏大幅加强实际控制 |
| 田和列为齐侯 | 前386年 | 田氏诸侯名号获周王承认 |
| 姜齐末君去世 | 前379年 | 旧君系最后遗存结束，与前386年不同 |

这也是为什么本图既保留春秋、战国分期，又另列这些具体事件。战国起点有前475年、前453年、前403年等口径；本图沿用前475年，不把分期选择伪装成一场真实发生的改朝换代。事件依据见[《晋世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj039.html)和[《田敬仲完世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj046.html)。

魏、楚、秦的改革都要解决军事竞争、财政收入、用人和贵族权力问题，但方案和结果并不相同。李悝与魏的农业、平籴主张，吴起在楚的改革，以及商鞅在秦的两轮变法，可以并读。吴起与商鞅都在支持他们的君主死后遭到杀害，却不能因此断定改革内容全部消失。秦的军功、户籍、县制与赋税建设，也同时增强了对民户的约束。参见[《汉书·食货志》](https://zh.wikisource.org/wiki/漢書/卷024)、[《孙子吴起列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj065.html)与[《商君列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj068.html)。

读图路径：**初税亩 → 李悝改革 → 商鞅首轮变法 → 迁咸阳与再变法**。前两条联系用于比较制度议题，不宣称后一国逐条抄用了前一国的政策。

## 四、七国竞争为何会转成秦的兼并

战国前中期的优势并不始终在秦。魏一度强盛，齐在桂陵、马陵重创魏；齐吞并宋后，又遭燕等五国联军进攻，田单依托残余据点恢复齐国。赵的胡服骑射与灭中山显示另一路扩张。把这些分支保留下来，才能看出秦的胜利经历了长期竞争，不能由统一结果倒推出此前每一步都已注定。参见[《魏世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj044.html)、[《赵世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj043.html)、[《乐毅列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj080.html)与[《田单列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj082.html)。

秦的优势来自相互配合的条件：变法后的征发与军功体系、对巴蜀的兼并、关中与成都平原的农业资源，以及战场、外交和对手内部局势。都江堰与郑国渠因此不只作为“科技成就”孤立展示，还接入资源与扩张的关系。水利工程的建立、修治、形成收益需要时间，不能在一张图上写成“修渠当年就足以统一”。参见[《秦本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj005.html)、[《河渠书》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj029.html)与[郑国渠灌区研究](https://agri-history.ihns.ac.cn/books/aa15.htm)。

长平是秦赵力量的重要转折，但秦围邯郸仍遭失败，魏楚救赵也改变了战局。楚失郢后还延续了五十余年，燕失蓟后还在辽东，赵王被俘后代地仍有赵氏政权。最后的兼并应拆开读：**韩前230年、邯郸前228年、魏前225年、楚王被俘前223年、燕与代前222年、齐前221年**。每个亡国点都有对应参与方，不把征服描绘成自愿融合。参见[《白起王翦列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj073.html)与[《秦始皇本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj006.html)。

## 五、思想、知识与技术也在回答时代问题

战争与政治竞争之外，人们还在讨论怎样判断善恶、怎样选择统治者、怎样生活。孔子与孟子围绕德、礼和仁政提出问题；墨家讨论兼爱、非攻、尚贤等议题；《老子》文本涉及道、无为及治理；荀子重视学习、礼与制度。这些思想既可能回应竞争，也可能批判竞争本身，不能把所有学术都解释成君主争天下的工具。参见[《孟子荀卿列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj074.html)、[墨家研究导论](https://plato.stanford.edu/archives/spr2020/entries/mohism/)与[《老子》研究导论](https://plato.stanford.edu/archives/fall2024/entries/laozi/)。

稷下与《吕氏春秋》显示政治赞助和学术汇集的不同方式：齐君招徕各家论学，吕不韦组织宾客编纂著作。不能因此把稷下当作具备现代学籍、统一课程和确切建校年的大学，也不能把多人、分期积累的先秦典籍都固定为某位作者在某一年完成。图中的墨家、《老子》和稷下用约略范围表示这一点。参见[《田敬仲完世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj046.html)与[《吕不韦列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj085.html)。

曾侯乙编钟让礼乐、铸造、声学知识与区域政治进入同一视野。其约前433年的墓葬背景属于古代历史时间，1978年属于现代考古发现时间，两者不能混写。本图用实物的古代年代定位，并没有声称该年发明了编钟。参见[曾侯乙编钟馆藏展览说明](https://www.nmns.edu.tw/ch/exhibitions/special-exhibitions/Exhibition-000016/)。

## 六、秦的统一、治理和迅速崩解

前221年既是完成主要兼并的节点，也是新帝国建立称号与行政体系的节点。郡县并非由秦始皇凭空发明；秦把此前形成的制度扩大到帝国范围。度量衡与文字标准化、驰道、北方设防和岭南置郡相互配合，也需要大量人力物力。图中把制度、工程、军事分开，以免“统一”一词遮住行政整合的过程。参见[《秦始皇本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj006.html)。

前213年禁毁部分典籍与前212年处死诸生分别成点。前者有书种和官藏等例外，后者的受刑者身份、范围和叙事需要辨析。前210年继承变局后，秦末起事从地方扩散，项梁在定陶败死又说明秦军并非立即丧失反击能力。项羽在巨鹿获胜、章邯后来投降，与刘邦另一路西进入关，共同构成秦的崩解；不是一场战役打完即产生汉帝国。参见[《陈涉世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj048.html)、[《项羽本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj007.html)与[《高祖本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj008.html)。

子婴投降采用常见前207年换算，而原图秦朝时期条采用通史常见前206年终点。秦汉以十月为岁首，同一段年际史事可能按秦末公历年份或汉元年编号列置，因此不补造一个精确公历日来消除分歧。鸿门会面也按常用前206年定位。读图时应把它们的实际次序与年表口径分别看待。

## 七、楚汉战争是多战场与联盟的竞争

项羽分封诸王后，刘邦受封汉王，这是西汉时期条前206年的起点，而不是称帝年。刘邦还定三秦取得关中基地，但在彭城遭到大败；韩信在赵、齐战场的胜利与正面的长期相持并行。鸿沟议和没有形成持久分治，汉军继续追击并在垓下会师，项羽败亡后刘邦才于前202年称帝。参见[《项羽本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj007.html)、[《高祖本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj008.html)与[《淮阴侯列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj092.html)。

读图可走两条会合路径：**彭城 → 鸿沟 → 垓下**，以及**井陉 → 潍水 → 垓下**。它们不是把所有胜负归结于某人的性格或一条妙计，而是展示多个战场如何汇集到同一决战。

此时“楚”“赵”“齐”还可能指秦末复立的政权，“韩王信”与淮阴侯韩信是不同人物。节点的参与方和说明保留这些区别，避免仅按同名把不同政治阶段拼成一条从未中断的国祚。

## 八、汉初如何把战后联盟变成可持续的统治

称帝并没有解决全部问题。汉初一方面沿用郡县及官僚行政，一方面保留、调整诸侯王，形成郡国并行格局。韩信、彭越被杀，英布起兵，反映皇权与功臣诸侯之间的矛盾。此后同姓诸侯也并非天然可靠：前154年七国之乱后，王国继续存在，但中央在前145年等阶段进一步削减其治国和任官权。参见[《高祖本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj008.html)、[《汉书·景帝纪》](https://zh.wikisource.org/wiki/漢書/卷005)与[《百官公卿表上》](https://m.gushiwen.cn/guwen/bookv_aac53f165025.aspx)。

恢复生产也有具体内容。复员、安置流亡人口和减轻部分负担，与曹参延续既有规制、文帝免田租、景帝以三十税一恢复田租，可以连成一条政策线。免田租并不等于免除口赋、徭役等一切负担；“休养生息”是对一系列政策取向的概括，不能代替逐项说明。参见[《曹相国世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj054.html)、[《汉书·文帝纪》](https://zh.wikisource.org/wiki/漢書/卷004)与[《景帝纪》](https://zh.wikisource.org/wiki/漢書/卷005)。

刑制改革尤其适合看“政策—后果—再调整”。文帝减除部分连坐、废诽谤妖言法，后来改革肉刑；但替代性的笞刑过重仍会致死，景帝又减笞数、规定刑具和执行方式。改革不是宣布善意就自动完成，制度的实际运行需要继续修正。参见[《孝文本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj010.html)与[《汉书·刑法志》](https://zh.wikisource.org/wiki/漢書/卷023)。

对外关系也并非只剩和平。白登之围后汉采取和亲等安排，文帝时仍需要周亚夫等部署边防；陆贾使南越取得册封关系，也不意味着汉已直接统治岭南。内政恢复、边境安全和地区自主性始终相互制约。参见[《匈奴列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj110.html)、[《刘敬叔孙通列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj099.html)与[《南越列传》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj113.html)。

本图以文帝前180年即位为文景阶段起点，前179年是其元年；景帝前157年即位，前156年为元年；武帝前141年即位，前140年为建元元年。把即位年与纪年元年区分开，便能顺畅接向原图前138年的张骞出使。

## 按问题选择阅读路线

| 想理解的问题 | 可在主图顺次查找的节点 |
| --- | --- |
| 王权怎样转向霸政 | 周郑交质、繻葛、葵丘、城濮、践土、弭兵 |
| 旧诸侯怎样分裂或被取代 | 晋阳、三家列侯、晋君余地结束、田常杀简公、田和列侯 |
| 国家怎样增加动员能力 | 初税亩、铸刑书、李悝改革、吴起变法、商鞅两轮变法、胡服骑射 |
| 秦为何逐渐占优 | 灭巴蜀、都江堰、郑国渠、伊阙、取郢、长平、邯郸解围、六国征服 |
| 思想如何回应秩序问题 | 孔子、墨家、《老子》、孟子、稷下、荀子、《吕氏春秋》 |
| 秦亡后为何仍有战争 | 沙丘变局、大泽乡、定陶、巨鹿、子婴投降、分封诸王、彭城、井陉、垓下 |
| 汉如何调整统治方式 | 郡国并行、复员、曹参为相、文帝刑制与田租改革、七国之乱、景帝限制王权 |

这些路线是阅读入口，不是排除其他因素的因果证明。史籍中的名言、人数与人物形象，应结合成书年代和叙述立场阅读；同年节点之间的线可以表示先后，但年份刻度本身不提供具体月日。
