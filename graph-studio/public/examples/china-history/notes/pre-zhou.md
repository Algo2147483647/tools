# 从二里头到西周末年

这一段从二里头的都邑与生产遗存起笔，接商代和西周，最后汇入原图的周平王东迁。按项目范围，不铺陈石器时代文化，不编夏朝世系；二里头单列为遗址，不预先指定为某个王朝都城。

阅读时可把两条线放在一起：一条是**都邑、资源与统治组织如何变化**，另一条是**我们凭什么知道这些变化**。二里头主要依靠考古材料，晚商有大量甲骨，西周又有丰富的青铜铭文。材料越来越具体，并不意味着每个年代和每种解释都已经确定。

图上，周朝以前的考古、技术和社会专题主要用点表示，保留七条时期线作为背景。专题点放在原年代窗口的较早端，方便顺着时间阅读；详情和条目目录仍列原范围，不能把点的坐标理解成确切发生年或发明年。

## 一、二里头：从城市空间看早期国家

在二里头，重点不是寻找某位传说中的王住过哪座宫殿，而是观察大型夯土建筑、道路、围墙、作坊和墓葬如何组合。修建、维护这样的都邑，需要集中材料和劳动力；不同居住、生产与墓葬空间的差异，又提示资源和身份存在分层。这些都是可以逐步检验的国家组织线索。[二里头布局的新发现](https://henanrd.gov.cn/2023/02-21/153384.html)

青铜礼器和玉器提供另一种观察尺度。制造一件青铜爵或镶嵌绿松石的器物，需要材料、技术和专门劳动；它的使用又与仪式和身份有关。把建筑与工艺一起读，才能看到都邑的组织能力，而不只是孤立地欣赏一件“国宝”。[二里头青铜爵](https://www.chnmuseum.cn/zp/zpml/kgfjp/202107/t20210722_250800.shtml)、[玉戚与镶嵌工艺](https://www.chnmuseum.cn/zp/zpml/kgfjp/202104/t20210416_249777.shtml)

图中约前1750—前1520年采用一种系列测年方案，并在节点保留其他年代方案。这里的数字不是一张已经确证的王朝年表。尤其二里头晚期与早商都邑有交叠，不能把两者画成在某个年份整齐换班。[二里头年代与归属的研究争论](https://www.cssn.cn/lsx/lsx_kgx/202210/t20221024_5552724.shtml)

## 二、早商：几个都邑与一张跨地区网络

早商不是只有一座孤立的首都。郑州商城的大型城垣、宫殿与生产遗存，偃师商城的宫城、祭祀区及池渠，都显示组织城市的能力。两处遗址可以相互比较，但不能仅靠古书中的地名，便将每一个建筑层指定给某位商王。[郑州商城](https://wwj.zhengzhou.gov.cn/wwyw/10096464.jhtml)、[偃师商城考古研究](https://www.ecsponline.com/yz/B62FF98C046A14E21BC352866B118A736000.pdf)

长江中游的盘龙城把观察范围拉向南方。它有宫殿、墓地与手工业区，器物既有本地特征，也与二里岗材料相联系。由此可以讨论人员、技术和物资如何往来；“有联系”与“被王都直接管理”仍是两种不同判断。[盘龙城遗址博物院基本陈列](https://www.plcsmuseum.com.cn/Exhibition/Detail/6067e169-f2df-47e6-bf6e-7ba6d510f740)

商汤及早期王统、仲丁以后迁徙与继承争夺、盘庚迁殷，构成传世叙事的一条主线。本图保留这些商史线索，但把约略时代窗口与已确认的单年事件区分开来，不将早商写成每一代都已与考古层位准确对上的帝王表。[《史记·殷本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj003.html)

## 三、殷墟晚商：王室、文字与社会生活

到殷墟阶段，宫殿宗庙、王陵、作坊和甲骨形成了更密集的材料组合。研究不再只依赖后来的回忆，还能阅读当时王室留下的文字。不过卜辞首先服务于占卜和王室事务，并不是面向全体居民编写的社会调查。[殷墟世界遗产资料](https://whc.unesco.org/en/list/1114)

武丁和妇好的活动适合交叉阅读。妇好既有甲骨记载，又有墓葬和带名器物，军事、祭祀、亲属身份因而能够放在同一个人身上讨论。王室的权力并不只是发号施令，还体现在组织征伐、调配资源和维系仪式关系之中。[故宫博物院关于妇好材料的讲座](https://www.dpm.org.cn/classify_detail/258152.html)

这张图也给农业、干支纪日、天象观察、专业手工业各留了入口。它们不是帝王故事之外的装饰：城市需要粮食和劳动供给，政治与仪式需要可持续的生产和记录。与此同时，祭祀遗存和墓葬中的暴力也属于社会史的一部分，不能只展示精美器物。[晚商社会展览](https://www.chnmuseum.cn/zl/zlhg/201812/t20181220_32319.shtml)、[甲骨中的纪时与天象](https://www.chnmuseum.cn/portals/0/web/zt/202012kxyjs/)

## 四、同时代的古蜀：三星堆与金沙

商王都之外，同期还存在有自身政治与祭祀传统的中心。三星堆青铜造像及器物坑，金沙的建筑与滨河祭祀场所，让成都平原进入这段历史。它们与其他地区有联系，同时保持鲜明的地方特色，不应只被当作中原王朝的附属注脚。[三星堆研究](https://www.cssn.cn/lsx/lsx_kgx/202303/t20230303_5601032.shtml)、[金沙祭祀区](https://www.jinshasitemuseum.com/node/216)

三星堆、金沙的材料存在年代重叠。因此图中的关系是比较和联系，而不是“旧都毁灭—新都立即接班”的固定故事。金沙节点只截取到西周末年，它在春秋的延续不会因专题边界而被抹去。[北京大学关于两地年代与联系的学术纪要](https://archaeology.pku.edu.cn/info/1031/35465.htm)

## 五、商周之际：打赢战争之后如何治理

周人的西方发展、文王时期的政治扩展、丰镐中心和牧野之战，构成王权更替的前史。图中把商末的帝乙、帝辛放回这一地区政治背景，不把商亡只归结为末王的个人道德。克商暂取通行的前1046年，但绝对年代仍有争论。利簋是重要的同时代材料，它提供的日序与事件线索，要经过综合研究才与公元年份相接。[利簋铭文](https://www.chnmuseum.cn/zp/zpml/kgfjp/202108/t20210802_250931.shtml)

克商并没有使新秩序立即稳定。武庚及监临殷地的安排、武王死后的继承问题、周公摄政和东方反抗，说明周人必须处理旧政治集团，也必须协调内部权力。东征与随后的封国、人口重组，才逐步把军事胜利转化成治理网络。[《鲁周公世家》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj033.html)

成周营建使东方治理获得重要据点，与关中中心相互配合。何尊把成王、成周及政治训示联系起来，也是理解早期“中国”用语的一项材料。这里指向当时的中心地域观念，不能据此直接划出现代国家范围。[何尊教学资料](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/pshe/references-and-resources/chinese-history/ancient_artifacts/Chapter2.pdf)

## 六、封国的不同起点：接上原图的诸侯线

分封网络中，各地的建立方式和后续发展并不相同。以下是进入原有春秋图的阅读入口，初封的约年不等于各国全程存续范围。

| 分支 | 本次补足的前史 | 后续阅读 |
| --- | --- | --- |
| 齐、鲁 | 太公封齐；伯禽就鲁；东方经营与王室分工 | 姜齐、齐桓公；鲁国与孔子 |
| 晋 | 唐叔封唐及晋国的起源叙事 | 晋国东周阶段、曲沃与晋的内部竞争 |
| 燕 | 琉璃河城址、墓葬与封授铭文 | 燕国东周阶段 |
| 卫、宋 | 康叔治理殷地；微子与商人祭祀传统 | 认识两种不同的周初政治安排；卫不与战国魏混同 |
| 楚 | 熊绎与周的早期联系及南方发展 | 楚国东周阶段 |
| 秦 | 非子、养马和西方封地 | 前770年以后的秦国 |
| 郑 | 前806年受封、西方基础与经营东方 | 东周郑国与王室关系 |

这些分支分别附有对应的《史记》篇章，燕国还引入琉璃河考古与铭文材料；可在[条目目录](./pre-zhou-catalog.md)按国名查阅。封授包含土地、人口、职事等具体内容，应理解为地区政治的重组，不能直接等同后世统一的郡县管理。[宜侯器铭文与东国研究](https://www.chnmuseum.cn/yj/xscg/xslw/201812/t20181224_36687.shtml)

## 七、西周治理：王命、资源、宗族与战争

成康时期的巩固，并不只有一句“天下安定”。大盂鼎让我们看到对先王的追述、对殷商的警戒，以及向王臣颁布命令和给予资源的行为。到较晚的颂器，册命程序又留下入朝、宣命、受赐等细节。把这些具体材料连起来，才看得到王权如何通过王臣与家族落实。[大盂鼎](https://www.chnmuseum.cn/portals/0/web/zt/202106dayuding/)、[颂器册命研究](https://www.chnmuseum.cn/yj/xscg/xslw/201812/t20181224_36456.shtml)

宗族和祖先不仅属于私人生活，也参与身份、资源与权力传递。器物组合和使用方式的变化则提供观察礼制的另一条路径。土地和人员赏赐可以由铭文研究，但不能由此直接推出各地都实行同一整齐的井田模式，或把后世礼书每一条规则都当成西周的普遍现实。[商周青铜鼎与礼制材料](https://www.chnmuseum.cn/portals/0/web/zt/202109lhwf/home/)

对外战争始终伴随这套秩序。昭王南征的挫折、穆王时期的活动，以及军队与后勤职事的铭文材料，提示王朝必须持续投入资源。到宣王时，虢季子白盘又将战功、宴飨和赏赐放在一起：军事成功也会重新分配贵族的威望与职权。[虢季子白盘](https://www.chnmuseum.cn/zp/zpml/csp/202008/t20200826_247376.shtml)

## 八、从厉王危机到东迁

厉王时期的王室与国人冲突，在前841年达到重大转折。厉王出奔，随后进入共和时期。前841年是通行连续纪年的起点，但“共和由谁主持”仍有不同文献解释，不能将这个古代称谓理解成现代共和政体。[《周本纪》](https://www.njmuseum.org.cn/files/wshl/rbbook/gb/25/shiji/sj004.html)、[清华简与西周史研究](https://www.tsinghua.edu.cn/info/1662/83766.htm)

宣王恢复王室权威，并未结束军事和政治压力。幽王时期的继承安排又牵动与申等群体的联盟关系，最终在前771年发生王室败亡。把这段历史只写成“褒姒一笑”会掩盖继承、婚姻联盟和战争的作用；传世文献与出土文本应对照阅读。[清华简对周史的补充与分歧](https://www.tsinghua.edu.cn/info/1182/49432.htm)

图中以“幽王败亡与西周结束”接入原有前770年东迁节点。这个连接是通行年表的入口；继承竞争和政治中心的转移经历了更长过程，不表示所有诸侯在一年内同时完成迁移。后续可继续读[春秋到汉初](./early-china.md)。

## 推荐的五条阅读路线

1. **都邑与组织**：二里头 → 郑州、偃师商城 → 殷墟 → 丰镐与成周。
2. **从实物到记录**：二里头青铜、玉器 → 甲骨卜辞 → 利簋、何尊 → 大盂鼎与册命铭文。
3. **战争与治理**：商代方国交战 → 牧野 → 周初反抗与东征 → 东方封国 → 西周军制与宣王战争。
4. **地方政治**：盘龙城、三星堆与金沙 → 周的封国网络 → 齐鲁晋燕、卫宋楚、秦郑的不同前史。
5. **王室危机**：厉王时期冲突 → 前841年 → 共和 → 宣王 → 幽王继承危机 → 前771年败亡 → 东迁。
