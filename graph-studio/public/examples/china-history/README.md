# 中国历史：分流与交汇

一张中文时间关系图，包含 **465 个事件、时期及年代范围**、**657 条关系**，选取公元前770年至2026年的部分历史节点（资料核对截止2026-10-14）。

默认使用 **Relation flow + Adaptive**。横向位置让关系更容易阅读；类别按事件所属政权组织，跨政权关系可以自由连接。纵向保持时间先后和同时性。

## 读图

- Type 按所属政权分类，如西汉、曹魏、蜀汉、北魏、唐、南宋。战争、思想、科技、制度等保留在 topic / theme 字段，并提供专题导读；多方事件另有 participants 字段。
- 点表示事件；条表示标题命名的时期、系列活动或明确标注的年代范围。毕昇条是记载年代范围，不是连续研制期；郑和条覆盖系列航行及航次间隔。
- 中华民国（1912年—今）与中华人民共和国（1949年—今）各有一条持续至今的政权线，终点随当前时间延伸。中华民国节点及[政权导读](./notes/polity.md#现代政权存续与执政阶段)注明国民党主导或执政阶段（1925—2000年、2008—2016年），不把政党轮替等同于政权终止。
- 自适应时间轴会拉开密集时期、压缩稀疏时期；不能用画面长度比较真实时长。切换到固定间隔时间轴，并设置每100年或其他间隔，即可比较时间距离。
- 线条交叉不表示关系合并。隋灭陈、靖康之变、南宋覆亡等汇合处都有明确事件节点；战争征服不等于自愿融合。
- 北魏分为东魏、西魏，再分别延续到北齐、北周，展示分支；隋与陈接入589年事件，展示不同类别之间的汇合。
- 868年《金刚经》同时联系造纸技术、译经文化与唐代时期；这些边说明主题背景，不宣称单一因果。
- 历史纪年没有公元0年。数据采用ISO天文年编号，如公元前221年写作 **-000220**。只知年份的值保留为年份，不虚构1月1日发生。

## 范围

这是一份用于阅读和演示的历史选编，不是完整中国通史，也不是疆域沿革或朝代正统表。未收录的时期不代表历史空白。政权时期可能并存，年表分期亦可能有不同口径；相关节点直接注明。现代部分延续到2026年，纳入国家建设、经济改革、政治运动、人权、公共卫生及国际关系。资料核对截止2026-10-14；最近选录事件不代表此后没有历史事件，不补造未核实事件或未来结果。
