# 原名、语言与中文对照

返回 [读图说明](./README.md)。中文用于解释；专名采用有关语言的规范形式。保留 Ἀθῆναι、Ῥωμανία、Русь、Україна、Österreich、Československo 等字形及变音符号，不能一概转成英语。

“原名”不意味着跨数千年存在一个不变的正式国号。古典和中世纪人名采用原语言的通行校订拼写；早期英语、法语等名称有时以现代规范字形呈现，不能当作原始手稿的逐字摹写。多语国家列出一种或几种有根据的称谓，不宣称排除其他官方语言。政权类别是检索入口，同类别下的历史政体变化以事件说明为准。

爱琴海考古文化不能凭后世地名推定未释读的当时国号。Ἑλλάς、Italia（诸邦）、Norden 和 Europa 是区域分类，不表示统一国家。希腊化诸王国、知识与文化、大西洋联系属于中文主题分类。
