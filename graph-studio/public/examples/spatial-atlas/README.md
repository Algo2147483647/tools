# Spatial Atlas · 空间图谱

打开任意画布后，底部 Spatial 半透明面板可收缩，支持切换投影、精确输入 Rotate / Tilt 角度、显示网格和标签。三维模式左键或单指拖动旋转，右键或 Shift 拖动平移；二维投影直接拖动平移。滚轮缩放，双指捏合缩放并平移。双击或双点节点查看或修改 `space`，使用顶部 Type 筛选星域、洲别或城市方位。

| Canvas | 内容 |
| --- | --- |
| all-sky.json | 全天 5,044 颗星表恒星和 3 个补充连线端点，743 条星座连线，Type 为 88 个星座区域。J2000 方向，六等星亮度截断。 |
| world-cities.json | 243 个重要城市，球坐标 `[6371, 经度, 纬度]`，标题使用当地原始语言，Type 为洲别。319 条连线仅表示区域内的邻近参考城市，不表示实际航线。 |
| beijing-roads.json | 历史北京简化路网中的环路及部分放射主干道，3,841 个路口、4,112 对有向端点。Type 为东北、西北、东南、西南几何分区。 |
| zero-dimensional.json | 0D：`space: []`。节点在索引托盘中分开展示，托盘距离没有空间意义。 |
| one-dimensional.json | 1D：单轴上的精确相对位置。 |
| polar.json | 2D：极坐标圆周。 |
| cylindrical.json | 3D：柱坐标螺旋。 |
| four-dimensional.json | 4D：超立方体；切换 View X/Y/Z 可观察第四维。投影重合的顶点没有被自动移动。 |
| five-dimensional.json | 5D：基向量；任意三条维度轴可用于投影。 |

星图的半径统一为 1，表示天空方向而非真实恒星距离。三维球体为透明线框，默认显示背面节点；在 Spatial 面板勾选 **Hide back points** 可隐藏背面节点、标签和相连的边，并随旋转实时更新。地图投影不受此开关影响。世界地图为等距圆柱投影；地球按球面近似。

北京画布是研究数据中的主干路样例，不是完整、实时或可导航的北京市路网。保留原始 `sourceXY`；`space` 使用局部近似东西/南北公里坐标。源数据未注明坐标基准，不能将其视为经过验证的 WGS84 坐标。道路连线使用已发布端点的直线段。

全部数据随工作区打包，打开后不依赖在线地图服务。来源与处理方式见 [SOURCES](./SOURCES.md)。
