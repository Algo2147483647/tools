# Spatial Atlas · 空间图谱

打开任意画布后，底部 Spatial 半透明面板可收缩，支持切换投影、精确输入 Rotate / Tilt 角度、显示网格和标签。三维模式左键或单指拖动旋转，右键或 Shift 拖动平移；二维投影直接拖动平移。滚轮缩放，双指捏合缩放并平移。双击或双点节点查看或修改 `space`，使用顶部 Type 筛选星域、洲别或地铁线路。

北京、上海地铁均可在 **Spatial → Display units** 调整每度对应的像素数，拉开站间距；普通缩放仍同步放大文字、圆点和线宽。两图都保留原始 WGS84 经纬度，不压缩远郊点位。上海同名但分离的国家会展中心、浦东南路站区分别定位，避免合并成虚构中点。

星图的半径统一为 1，表示天空方向而非真实恒星距离。三维球体为透明线框，默认显示背面节点；在 Spatial 面板勾选 **Hide back points** 可隐藏背面节点、标签和相连的边，并随旋转实时更新。地图投影不受此开关影响。世界地图为等距圆柱投影；地球按球面近似。

北京画布包含 1–19 号线、S1、昌平、房山、燕房、亦庄、首都机场、大兴机场、西郊及亦庄 T1；1 号线与八通线、4 号线与大兴线分别按贯通运营线路显示。包含 18 号线、17 号线中段及望京西站、6 号线潞阳和通运门站。每站使用一个 WGS84 经纬度点，`space` 原样保留 `[经度, 纬度]`；城郊与城区采用同一比例，不压缩远郊，不人为移动或错开换乘站。画布为经纬度角度坐标图，坐标轴单位为度。

同名换乘站合并为一个节点，节点说明列出全部换乘线路。木樨地、大钟寺、巴沟和荣昌东街标记为出站换乘。线路使用运营方色彩，换乘站用深灰色标记；两线共用相邻车站时交替显示两种线色。在 Type 中选择线路可查看该线全部车站与连线。2、10 号线闭环；首都机场线机场段用箭头表示三元桥 → 3 号航站楼 → 2 号航站楼 → 三元桥。

八角游乐园封站期间不作为运营停靠站，古城与八宝山直接相连；14 号线陶然桥、高家园，17 号线广渠门外及 T1 老观里不列入已开放站点。7 号线广渠门外和 12 号线高家园正常保留。数据为核对日快照，不反映临时限流、当天停运或实时列车情况。

坐标取自 OpenStreetMap 的真实车站或轨道停靠点，并在节点中保留来源链接；朱房北采用已标注车站轮廓的几何中心。保留来源坐标精度，不将公开地图数据称为测绘级或站台级测量成果。连线表示相邻站关系，不是轨道中心线。二维适配以实际节点和标签边界为准，不计入无关留白。

全部数据随工作区打包，打开后不依赖在线地图服务。来源与处理方式见 [SOURCES](./SOURCES.md)。
