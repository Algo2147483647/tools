# Set theory and mathematical logic

Syntax, semantics, computability and axiomatic set theory, with explicit metatheoretic assumptions.

## Scope

Selected advanced-undergraduate and beginning-graduate core with advanced gateways. Entries give precise scoped statements and proof ideas, not full proofs or exhaustive courses.

## Assumed background

Proof techniques, elementary sets and functions; elementary arithmetic for coding computations.

## Learning outcomes

- Distinguish provability, truth in a structure and logical validity.
- State incompleteness with effective-axiomatization and consistency assumptions.
- Distinguish internal cardinality, external cardinality and relative consistency.

## Problems for active study

1. Use compactness to construct a model of the theory of the natural numbers with an element greater than every standard numeral.
2. Reconstruct Cantor's diagonal proof without choice and explain why it does not identify the cardinality of the continuum with aleph-one.

## Reference reading

- **LOGIC** — Open Logic Project contributors. [Open Logic Text](https://builds.openlogicproject.org/open-logic-complete.pdf). Living open textbook; first-order logic, computability and set theory.
- **MODEL** — David Marker. [Model Theory: An Introduction](https://homepages.math.uic.edu/~marker/mt-intro.html). Springer GTM 217, 2002.
- **SET** — Joel David Hamkins. [How the Continuum Hypothesis Could Have Been Fundamental](https://jdh.hamkins.org/wp-content/uploads/Slides-CH-could-have-been-fundamental-Hamkins-Oslo-June-2024.pdf). Oslo lecture slides, June 2024; independence background.
- **FORCING** — Joel David Hamkins. [Lectures on Set Theory](https://jdh.hamkins.org/lectures-on-set-theory-beijing-june-2025/). Peking University, June 2025; Lecture 3: Forcing.
