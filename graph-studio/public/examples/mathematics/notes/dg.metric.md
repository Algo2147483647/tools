# Riemannian metrics

Differential geometry · Definition · Core

Stable ID: `dg.metric`

## Statement

A Riemannian metric is a smooth positive-definite inner product on each tangent space. It defines lengths, angles, curve lengths and an induced distance on each connected component.

## Hypotheses and conventions

Positive definiteness distinguishes this setting from pseudo-Riemannian geometry.

## Example

The sphere inherits its round metric from Euclidean space.

## Scope and common pitfalls

Different metrics on the same smooth manifold can have different curvature and completeness.
