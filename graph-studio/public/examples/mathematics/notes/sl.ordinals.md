# Ordinals and well-orders

Set theory and mathematical logic · Definition · Core

Stable ID: `sl.ordinals`

## Statement

An ordinal is a transitive set well-ordered by membership. Each well-ordered set is order-isomorphic to a unique ordinal.

## Hypotheses and conventions

This uses the standard von Neumann representation.

## Example

$\omega+1$ and $1+\omega=\omega$ show that ordinal addition is not commutative.

## Scope and common pitfalls

Order type and cardinal size are different invariants.
