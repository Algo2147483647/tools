# Compactness theorem

Set theory and mathematical logic · Theorem · Core

Stable ID: `sl.compactness`

## Statement

A first-order theory has a model if every finite subset has a model.

## Hypotheses and conventions

This concerns finitary first-order logic, with ordinary classical semantics.

## Example

Adding a constant larger than every standard numeral produces a nonstandard model of arithmetic by compactness.

## Scope and common pitfalls

Compactness fails for full second-order semantics.

## Proof idea

A formal contradiction uses only finitely many axioms; completeness supplies the model.

This is a proof strategy; details and intermediate lemmas are in the references.
