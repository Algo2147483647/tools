# Weak and weak-star topologies

Functional analysis · Definition · Core

Stable ID: `fa.weak`

Weak and weak-star topologies test convergence against different families of functionals.

## Statement

Weak convergence in X means convergence against every element of $X^*$. Weak-star convergence in $X^*$ means pointwise convergence on X.

## Hypotheses and conventions

The specified predual determines the weak-star topology.

## Example

An orthonormal sequence in a Hilbert space converges weakly to zero but not in norm.

## Scope and common pitfalls

Weak and weak-star topologies generally differ; their compactness is naturally formulated using nets, not only sequences.
