# Sets, functions and relations

Set theory and mathematical logic · Definition · Core

Stable ID: `sl.sets`

## Statement

Sets collect elements; a binary relation is a subset of a Cartesian product. A function is a relation assigning exactly one output to each input in its domain.

## Hypotheses and conventions

Collections too large to be sets are handled as classes in the metatheory or in a class theory.

## Example

An equivalence relation partitions a set; its quotient consists of equivalence classes.

## Scope and common pitfalls

Unrestricted comprehension is inconsistent: the Russell collection cannot be a set.
