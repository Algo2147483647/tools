# Inverse, implicit and constant-rank theorems

Differential geometry · Theorem · Core

Stable ID: `dg.rank`

## Statement

An invertible differential gives local smooth coordinates in which a map is a diffeomorphism. A constant-rank map has local normal form consisting of a projection followed by an inclusion.

## Hypotheses and conventions

Invertibility is required at the point for the inverse theorem; rank is constant on a neighborhood for the constant-rank theorem.

## Example

A regular level set of a smooth real-valued function is a codimension-one submanifold.

## Scope and common pitfalls

A critical level can be singular even when the map is smooth.

## Proof idea

Apply the Euclidean inverse function theorem to selected coordinate components and solve for the remaining ones.

This is a proof strategy; details and intermediate lemmas are in the references.
