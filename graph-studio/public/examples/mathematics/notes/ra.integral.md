# Lebesgue integration

Real analysis · Construction · Core

Stable ID: `ra.integral`

Lebesgue integration builds integrals from measurable simple functions.

## Statement

For measurable $f\ge0$, define $\int f\,d\mu$ by suprema of integrals of simple functions below $f$. For signed or complex functions, integrability requires $\int|f|\,d\mu<\infty$.

## Hypotheses and conventions

Functions equal almost everywhere have the same integral.

## Example

The indicator of the rationals has Lebesgue integral zero on $[0,1]$ but is not Riemann integrable there.

## Scope and common pitfalls

The expression $\infty-\infty$ is never an integral value.
