# Smooth manifolds and smooth maps

Differential geometry · Definition · Core

Stable ID: `dg.smooth`

## Statement

A smooth structure is a maximal atlas whose coordinate changes are smooth. A map between smooth manifolds is smooth when its coordinate representations are smooth.

## Hypotheses and conventions

Manifolds are finite dimensional, Hausdorff and second countable; boundary is excluded unless stated.

## Example

The sphere has compatible charts obtained by stereographic projection.

## Scope and common pitfalls

A homeomorphism need not be a diffeomorphism; topology alone does not specify a smooth structure.
