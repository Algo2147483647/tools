# Bounded linear operators

Functional analysis · Definition · Core

Stable ID: `fa.operators`

Continuity of a linear map is equivalent to a uniform norm bound.

## Statement

A linear map $T:X\to Y$ between normed spaces is bounded if $\|Tx\|\le C\|x\|$. This is equivalent to continuity. Its operator norm is $\sup_{\|x\|\le1}\|Tx\|$.

## Hypotheses and conventions

Boundedness is a global linear estimate.

## Example

Differentiation is bounded from C1 with its C1 norm to C with its sup norm, but not with only the sup norm on the domain.

## Scope and common pitfalls

An operator's boundedness depends on its domain and the chosen norms.
