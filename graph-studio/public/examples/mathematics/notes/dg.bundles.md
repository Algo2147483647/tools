# Vector bundles and connections

Differential geometry · Definition · Advanced gateway

Stable ID: `dg.bundles`

Vector bundles carry local linear data; connections differentiate their sections.

## Statement

A vector bundle is locally a product with a fixed vector space and linear transition maps. A connection differentiates sections with $\nabla(fs)=df\otimes s+f\nabla s$.

## Hypotheses and conventions

A connection is additional structure, not part of the definition of a vector bundle.

## Example

The tangent bundle of a sphere is a natural vector bundle that need not be trivial.

## Scope and common pitfalls

A local frame need not extend to a global frame.
