# Structures, satisfaction and elementary maps

Set theory and mathematical logic · Definition · Core

Stable ID: `sl.semantics`

Structures interpret syntax; elementary maps preserve all first-order formulas.

## Statement

A structure interprets the symbols on a nonempty domain. Satisfaction $\mathcal M\models\varphi[\bar a]$ is defined recursively. An elementary embedding preserves every first-order formula with parameters.

## Hypotheses and conventions

Classical first-order semantics and nonempty domains are used.

## Example

The inclusion of one group in another preserves operations but need not be elementary.

## Scope and common pitfalls

Truth in one structure is different from validity in all structures.
