# Gödel completeness theorem

Set theory and mathematical logic · Theorem · Core

Stable ID: `sl.completeness`

Every first-order semantic consequence has a finite formal proof.

## Statement

For classical first-order logic, $T\models\varphi$ implies $T\vdash\varphi$. Equivalently, every syntactically consistent first-order theory has a model.

## Hypotheses and conventions

The ambient metatheory supplies ordinary classical set-theoretic reasoning.

## Example

Semantic impossibility of a first-order configuration yields a finite formal refutation.

## Scope and common pitfalls

Completeness of logic does not mean that each particular theory decides every sentence.

## Proof idea

Add Henkin witnesses, extend to a maximally consistent theory and build its term model.

This is a proof strategy; details and intermediate lemmas are in the references.
