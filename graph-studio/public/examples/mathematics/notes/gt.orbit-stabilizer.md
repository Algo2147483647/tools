# Orbit–stabilizer theorem

Group theory · Theorem · Core

Stable ID: `gt.orbit-stabilizer`

An orbit is identified with the cosets of a point stabilizer.

## Statement

For x in a G-set, the map $G/G_x\to Gx$ is a bijection. If G is finite, $|Gx|=|G|/|G_x|$.

## Hypotheses and conventions

The quotient here is a coset set; the stabilizer need not be normal.

## Example

Counting a polygon's vertex orbit determines the size of its vertex stabilizer.

## Scope and common pitfalls

Transitivity does not imply that the action is free.

## Proof idea

Two group elements send x to the same point exactly when they lie in the same stabilizer coset.

This is a proof strategy; details and intermediate lemmas are in the references.
