# Cardinals and countability

Set theory and mathematical logic · Definition · Core

Stable ID: `sl.cardinals`

## Statement

Two sets have the same cardinality if there is a bijection between them. In ZFC each cardinal has a least ordinal representative, and any two cardinalities are comparable.

## Hypotheses and conventions

Well-orderability of every set uses choice.

## Example

The integers and rationals are countable; the real numbers are not.

## Scope and common pitfalls

An infinite subset can have the same cardinality as its proper superset.
