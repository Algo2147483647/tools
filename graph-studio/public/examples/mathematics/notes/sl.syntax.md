# First-order syntax and proofs

Set theory and mathematical logic · Definition · Core

Stable ID: `sl.syntax`

## Statement

A first-order language specifies function, relation and constant symbols with arities. Terms and formulas are finite strings built recursively; formal proofs use fixed effective inference rules.

## Hypotheses and conventions

Quantifiers range over individuals, not over all subsets or relations.

## Example

In the language of groups, associativity is a first-order sentence.

## Scope and common pitfalls

A formula with free variables differs from a sentence; bound-variable renaming must avoid capture.
