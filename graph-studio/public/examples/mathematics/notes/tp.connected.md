# Connectedness and path connectedness

Topology · Definition · Core

Stable ID: `tp.connected`

## Statement

A connected space has no decomposition into two disjoint nonempty open subsets. A path-connected space joins every two points by a continuous map from the unit interval.

## Hypotheses and conventions

Path connectedness implies connectedness; the converse requires further hypotheses.

## Example

The topologist's sine curve is connected but not path connected.

## Scope and common pitfalls

Local connectedness and global connectedness are different properties.
