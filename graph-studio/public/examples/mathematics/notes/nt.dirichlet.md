# Dirichlet's theorem on primes

Number theory · Theorem · Core

Stable ID: `nt.dirichlet`

Every residue class coprime to its modulus contains infinitely many primes.

## Statement

If $\gcd(a,q)=1$ and $q\ge1$, infinitely many primes satisfy $p\equiv a\pmod q$.

## Hypotheses and conventions

The residue class is coprime to the modulus.

## Example

There are infinitely many primes congruent to 3 modulo 4.

## Scope and common pitfalls

Infinitude alone supplies no asymptotic count.

## Proof idea

Use character orthogonality and nonvanishing of nonprincipal L-functions at one.

This is a proof strategy; details and intermediate lemmas are in the references.
