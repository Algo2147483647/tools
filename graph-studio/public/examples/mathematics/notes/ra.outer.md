# Carathéodory extension

Real analysis · Theorem · Core

Stable ID: `ra.outer`

## Statement

A premeasure on an algebra extends to a measure on the generated sigma-algebra via its induced outer measure. The extension is unique under sigma-finiteness of the premeasure.

## Hypotheses and conventions

The premeasure is countably additive whenever the disjoint union remains in the algebra.

## Example

Lengths of half-open intervals generate Lebesgue measure after extension and completion.

## Scope and common pitfalls

Outer measure alone is only countably subadditive; measurability must be imposed.

## Proof idea

Declare a set measurable when it splits every outer measure additively; verify countable additivity on these sets.

This is a proof strategy; details and intermediate lemmas are in the references.
