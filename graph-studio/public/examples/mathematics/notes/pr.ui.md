# Uniform integrability

Probability theory · Definition · Core

Stable ID: `pr.ui`

Uniform tail control is the missing ingredient for convergence in mean.

## Statement

A family $\mathcal X\subset L^1$ is uniformly integrable if $\sup_{X\in\mathcal X}\mathbb E[|X|1_{|X|>K}]\to0$. For integrable X, convergence in probability plus uniform integrability of the sequence is equivalent to $L^1$ convergence.

## Hypotheses and conventions

All variables are on one probability space.

## Example

A uniform Lp bound for some p greater than one implies uniform integrability.

## Scope and common pitfalls

Uniform L1 boundedness alone allows rare tall spikes and is insufficient.
