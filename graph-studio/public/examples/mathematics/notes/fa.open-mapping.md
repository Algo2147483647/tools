# Open mapping and bounded inverse

Functional analysis · Theorem · Core

Stable ID: `fa.open-mapping`

## Statement

A surjective bounded linear map between Banach spaces is open. A bounded linear bijection between Banach spaces therefore has bounded inverse.

## Hypotheses and conventions

Both spaces are complete, and surjectivity is required for openness.

## Example

Equivalent Banach norms can be proved equivalent by the bounded inverse theorem when the identity map is a bounded bijection.

## Scope and common pitfalls

An algebraic inverse need not be continuous when completeness fails.

## Proof idea

Baire gives a ball in the closure of an image; a convergent correction series upgrades closure to actual inclusion.

This is a proof strategy; details and intermediate lemmas are in the references.
