# Transfinite induction and recursion

Set theory and mathematical logic · Theorem · Core

Stable ID: `sl.transfinite`

## Statement

For a well-ordered domain, induction from all earlier stages proves a property at every stage. A functional rule assigning a set from each prior segment defines a unique recursively constructed sequence along any ordinal.

## Hypotheses and conventions

The recursive rule must be functional; replacement collects the values into sets at set-sized stages.

## Example

The cumulative hierarchy and ordinal arithmetic are defined recursively.

## Scope and common pitfalls

At limit stages one must specify the rule; there is no immediate predecessor.

## Proof idea

A least counterexample proves induction; compatible partial solutions are glued by uniqueness and extended at each stage.

This is a proof strategy; details and intermediate lemmas are in the references.
