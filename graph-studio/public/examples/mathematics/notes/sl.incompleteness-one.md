# First incompleteness theorem

Set theory and mathematical logic · Theorem · Core

Stable ID: `sl.incompleteness-one`

## Statement

Every consistent computably axiomatizable theory extending Robinson arithmetic Q is incomplete: some sentence is neither provable nor refutable in the theory.

## Hypotheses and conventions

This is the Gödel–Rosser formulation; consistency, effective axiomatization and sufficient arithmetic are essential.

## Example

If PA is consistent, it does not decide all arithmetic sentences.

## Scope and common pitfalls

Complete theories exist, but true arithmetic is not computably axiomatizable; logical completeness is a different statement.

## Proof idea

Encode syntax arithmetically and diagonalize; Rosser's refinement needs consistency rather than omega-consistency.

This is a proof strategy; details and intermediate lemmas are in the references.
