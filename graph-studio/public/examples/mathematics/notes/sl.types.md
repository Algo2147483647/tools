# Types and saturation

Set theory and mathematical logic · Research gateway · Advanced gateway

Stable ID: `sl.types`

## Statement

A type over parameters is a consistent collection of formulas in fixed free variables. A saturated model realizes types over parameter sets smaller than its saturation cardinal.

## Hypotheses and conventions

Specify the theory, the parameter set and the saturation cardinal.

## Example

The type saying a number exceeds each standard numeral is realized in a suitable nonstandard model.

## Scope and common pitfalls

Compactness can realize a type in an extension without making a given model saturated.
