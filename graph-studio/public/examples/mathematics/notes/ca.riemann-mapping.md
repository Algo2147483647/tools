# Riemann mapping theorem

Complex analysis · Theorem · Core

Stable ID: `ca.riemann-mapping`

Proper simply connected plane domains are conformally equivalent to the disk.

## Statement

Every nonempty simply connected proper plane domain is biholomorphic to $\mathbb D$. Specifying an interior image of zero and a positive real derivative fixes the normalized inverse map uniquely.

## Hypotheses and conventions

The domain is open, connected, simply connected, and different from the whole plane.

## Example

The upper half-plane is mapped to the disk by a Möbius transformation.

## Scope and common pitfalls

The theorem does not by itself assert continuous extension to an arbitrary boundary.

## Proof idea

Optimize a normalized univalent family using normality; a missing image point would permit an improving map.

This is a proof strategy; details and intermediate lemmas are in the references.
