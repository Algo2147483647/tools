# Groups and homomorphisms

Group theory · Definition · Core

Stable ID: `gt.groups`

## Statement

A group is a set with an associative multiplication, an identity and inverses. A homomorphism preserves multiplication and therefore identities and inverses.

## Hypotheses and conventions

Commutativity is an additional condition, not part of the group axioms.

## Example

$S_n$, invertible matrices, and the additive integers are basic examples.

## Scope and common pitfalls

A set of symmetries must be closed under composition and inverse to form a group.
