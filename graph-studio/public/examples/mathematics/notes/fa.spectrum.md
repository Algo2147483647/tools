# Spectrum and resolvent

Functional analysis · Definition · Core

Stable ID: `fa.spectrum`

The spectrum records failure of a bounded everywhere-defined inverse.

## Statement

For a bounded operator T on a complex Banach space, $\sigma(T)$ consists of scalars for which $T-\lambda I$ has no bounded everywhere-defined inverse. It is nonempty and compact.

## Hypotheses and conventions

Nonemptiness uses the complex scalar field and a nonzero Banach space.

## Example

The unilateral shift has spectral points that are not eigenvalues.

## Scope and common pitfalls

In infinite dimensions, spectrum and set of eigenvalues are not the same.
