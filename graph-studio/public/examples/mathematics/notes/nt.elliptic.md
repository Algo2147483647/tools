# Elliptic curves and rational points

Number theory · Definition · Core

Stable ID: `nt.elliptic`

A pointed smooth projective genus-one curve carries an arithmetic group law.

## Statement

An elliptic curve over K is a smooth projective geometrically integral genus-one curve with a chosen K-rational point. In characteristic different from 2 and 3 it has a model $y^2=x^3+Ax+B$, $4A^3+27B^2\ne0$.

## Hypotheses and conventions

The projective point at infinity is the identity in this model.

## Example

Chords and tangents describe the group law.

## Scope and common pitfalls

A singular cubic is not an elliptic curve.
