# Cantor's theorem

Set theory and mathematical logic · Theorem · Core

Stable ID: `sl.cantor`

No set can be mapped onto its entire power set.

## Statement

For every set A there is no surjection $A\to\mathcal P(A)$; thus A has strictly smaller cardinality than its power set.

## Hypotheses and conventions

The diagonal argument requires no axiom of choice.

## Example

$\mathcal P(\mathbb N)$ is uncountable.

## Scope and common pitfalls

There is no largest cardinal and no set of all sets.

## Proof idea

For a proposed surjection f, the set of a not belonging to f(a) differs from every image value.

This is a proof strategy; details and intermediate lemmas are in the references.
