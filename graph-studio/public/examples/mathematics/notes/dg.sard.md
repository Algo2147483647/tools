# Sard's theorem and regular values

Differential geometry · Theorem · Core

Stable ID: `dg.sard`

## Statement

For a smooth map between finite-dimensional smooth manifolds, the set of critical values has measure zero in every target coordinate chart.

## Hypotheses and conventions

The map is smooth here; finite differentiability versions require a dimension-dependent derivative bound.

## Example

A generic target value gives a regular level set when the preimage is nonempty.

## Scope and common pitfalls

A null set of critical values does not mean the set of critical points is small.

## Proof idea

Reduce to Euclidean charts, separate rank strata and control images of critical sets by Taylor estimates.

This is a proof strategy; details and intermediate lemmas are in the references.
