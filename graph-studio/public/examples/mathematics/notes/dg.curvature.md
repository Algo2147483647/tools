# Curvature and sectional curvature

Differential geometry · Definition · Core

Stable ID: `dg.curvature`

Curvature measures the failure of covariant derivatives to commute.

## Statement

Use $R(X,Y)Z=\nabla_X\nabla_YZ-\nabla_Y\nabla_XZ-\nabla_{[X,Y]}Z$. For a plane spanned by X,Y, $K=\langle R(X,Y)Y,X\rangle/(|X|^2|Y|^2-\langle X,Y\rangle^2)$.

## Hypotheses and conventions

X,Y must be linearly independent; curvature sign conventions vary between texts.

## Example

With this convention the unit round sphere has sectional curvature +1.

## Scope and common pitfalls

Coordinate-dependent connection coefficients should not be mistaken for curvature.
