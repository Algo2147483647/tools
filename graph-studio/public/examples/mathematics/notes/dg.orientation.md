# Orientation and integration

Differential geometry · Definition · Core

Stable ID: `dg.orientation`

## Statement

An orientation consistently chooses positive ordered tangent bases. Compactly supported top-degree forms can be integrated on oriented manifolds using oriented charts and a partition of unity.

## Hypotheses and conventions

Integration of forms requires orientation; densities provide a different orientation-free construction.

## Example

A nowhere-vanishing top form determines an orientation.

## Scope and common pitfalls

The Mobius strip admits no global orientation.
