# Prime spectrum and Zariski topology

Algebraic geometry · Construction · Core

Stable ID: `ag.spec`

The prime spectrum equips all prime ideals with the Zariski topology.

## Statement

$\operatorname{Spec}A$ is the set of prime ideals, with closed subsets $V(I)=\{\mathfrak p:I\subseteq\mathfrak p\}$. Basic opens $D(f)$ consist of primes not containing f.

## Hypotheses and conventions

All prime ideals are retained, including nonmaximal generic points.

## Example

$\operatorname{Spec}\mathbb Z$ has closed points (p) and a generic point (0).

## Scope and common pitfalls

The Zariski topology is usually not Hausdorff.
