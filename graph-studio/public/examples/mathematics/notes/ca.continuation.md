# Analytic continuation and monodromy

Complex analysis · Theorem · Core

Stable ID: `ca.continuation`

## Statement

Local holomorphic germs continue uniquely along a fixed chain where overlaps agree. If a germ can be continued along every path in a simply connected domain, monodromy makes the continuation single-valued.

## Hypotheses and conventions

Continuation along all paths is an extra existence assumption, not a consequence of simple connectivity alone.

## Example

Continuing a logarithm around zero changes its value by an integer multiple of $2\pi i$.

## Scope and common pitfalls

Uniqueness on overlaps does not eliminate monodromy in a multiply connected domain.

## Proof idea

Use the identity theorem and deform path chains through a homotopy.

This is a proof strategy; details and intermediate lemmas are in the references.
