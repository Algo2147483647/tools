# Egorov and Lusin approximation

Real analysis · Theorem · Core

Stable ID: `ra.egorov`

## Statement

On a finite measure space, almost-everywhere convergence is uniform outside a set of arbitrarily small measure. For a finite-valued measurable function on a finite-measure Lebesgue measurable set, restriction to a suitable compact subset is continuous with arbitrarily small measure loss.

## Hypotheses and conventions

The first assertion is Egorov; the second is a Euclidean Lebesgue version of Lusin.

## Example

Approximate a measurable function by continuous behavior after discarding a small exceptional set.

## Scope and common pitfalls

Neither result makes the original function globally continuous or the original convergence uniformly valid everywhere.

## Proof idea

Control a countable family of exceptional sets; for Lusin combine simple-function approximation with regularity.

This is a proof strategy; details and intermediate lemmas are in the references.
