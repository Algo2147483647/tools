# Ideal class group

Number theory · Definition · Core

Stable ID: `nt.class-group`

Ideal classes measure the obstruction to principal ideal factorization.

## Statement

The group of nonzero fractional ideals modulo principal fractional ideals is $\operatorname{Cl}(K)$. It is trivial exactly when $\mathcal O_K$ is a PID, equivalently a UFD.

## Hypotheses and conventions

Fractional ideals are invertible in a Dedekind domain.

## Example

$\mathbb Q(\sqrt{-5})$ has class number two.

## Scope and common pitfalls

Class number measures failure of principality, not the number of prime ideals.
