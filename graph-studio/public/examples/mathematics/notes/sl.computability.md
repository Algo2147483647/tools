# Computability and enumerable theories

Set theory and mathematical logic · Definition · Core

Stable ID: `sl.computability`

## Statement

A set is decidable if a Turing machine always halts and correctly decides membership. It is computably enumerable if a machine enumerates its members, equivalently semidecides membership.

## Hypotheses and conventions

Fix an effective coding of finite strings, machines and proofs.

## Example

The theorems of an effectively axiomatized theory are computably enumerable.

## Scope and common pitfalls

Enumerable need not mean decidable; failure of a search to halt is not a negative answer.
