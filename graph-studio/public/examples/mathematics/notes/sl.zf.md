# ZF axioms and the cumulative hierarchy

Set theory and mathematical logic · Definition · Core

Stable ID: `sl.zf`

ZF organizes sets by explicit axioms and the cumulative hierarchy.

## Statement

ZF consists of extensionality, empty set, pairing, union, power set, infinity, separation and replacement schemes, and foundation. The hierarchy has $V_0=\varnothing$, $V_{\alpha+1}=\mathcal P(V_\alpha)$ and unions at limit stages.

## Hypotheses and conventions

ZF does not include the axiom of choice; the schemes contain infinitely many first-order instances.

## Example

Separation selects a subset of an already given set.

## Scope and common pitfalls

The cumulative hierarchy is a proper class, not a set containing all sets.
