# Lp spaces

Real analysis · Definition · Core

Stable ID: `ra.lp`

Lp spaces measure integrability modulo equality almost everywhere.

## Statement

For $1\le p<\infty$, $L^p(\mu)$ consists of measurable functions modulo almost-everywhere equality with norm $(\int |f|^p\,d\mu)^{1/p}$. The $L^\infty$ norm is essential supremum.

## Hypotheses and conventions

The quotient by null sets makes the norm definite.

## Example

On a finite measure space, $L^q\subseteq L^p$ when $q\ge p$.

## Scope and common pitfalls

This inclusion need not hold on an infinite measure space; $0<p<1$ does not give a norm by this formula.
