# 爱琴海、希腊诸邦与 Roma

[总览](../README.md) · [逐项目录及来源](./ancient-catalog.md) · [原名对照](../NAMES.md)

从 Κνωσός 的宫殿与 Μυκῆναι 的墓葬开始，首先看到的是资源组织、行政记录和跨海联系。它们不是后来民族国家的缩小版本。Linear B 记录早期希腊语，不能据此替尚未释读的 Linear A 发明国号、君王世系。Θήρα 喷发只设一个约年点，保留测年争议；宫殿衰落也并非整个地区在同一天突然“文明消失”。

## 诸邦、联盟与政治参与

字母传播、海外聚落和贸易网络为诸邦社会提供背景。Ἀθῆναι 的 Δράκων、Σόλων、Πεισίστρατος、Κλεισθένης 各自代表不同的法律、权力与公民组织变化。所谓民主的参与者范围有限，妇女、奴隶和外来居民并未因此取得平等政治权利。Σπάρτη 与其他诸邦也不能仅按雅典制度的“进步程度”排列。

Μαραθών、Σαλαμίς 和 Πλάταιαι 的战争线通向海上联盟及城邦之间的支配关系；Παρθενών 建设与战争财政也可并读。Πελοποννησιακός πόλεμος、瘟疫、Σικελία 远征、投降和 Σωκράτης 审判分成点，以免一条战争线吞掉政治与社会变化。宗教、戏剧和哲学活动发生在奴役、迁徙与战争共同构成的社会中。

Μακεδονία 的崛起改变诸邦力量关系。Ἀλέξανδρος 的远征、死亡和继业战争分别处理；Ἑλλάς、埃及和西亚的交流并非希腊文化单向覆盖其他社会。Εὐκλείδης 的知识活动放在这些新的城市、王室与学术网络中理解。

## Roma 的扩张与制度冲突

前753年建城、前509年共和国起点属于传统纪年，不能当作现代档案式精确日期。平民斗争、十二表法、公民权及军役问题与意大利扩张交织。对 Carthago 的战争和对东地中海的征服汇入共和国后期的资源、军队和权力竞争，但“扩张必然导致独裁”仍是过度简化。

Tiberius 与 Gaius Gracchus、同盟者战争、Sulla、Spartacus、Caesar、内战和 Actium 依次提供不同切面。Augustus 的前27年安排是元首制的阅读界标，并非前一天所有共和制度完好、第二天全部消失。行省统治、道路、城市、军队、公民身份与奴隶劳动共同维系帝国。

## 帝国重组与宗教变化

Caracalla 的公民权敕令、三世纪危机、Diocletianus 重组和四帝制说明皇权并非固定模式。基督教传播、迫害、宗教宽容、教义会议与国家扶持分成不同节点；313年不等于当即确立国教。疫病与人口变动也不能只作为皇帝故事的插曲。

395年分治后，西部朝廷和东部帝国形成两条相连线路。410、455年的 Roma 遭劫与476年的废帝不是同一事件。476年尤其不表示罗马法律、居民身份或东部帝国同时消亡；下一篇的 Ῥωμανία 正是延续中的历史。图中的时期线只负责界标，重要变化仍以点呈现。
